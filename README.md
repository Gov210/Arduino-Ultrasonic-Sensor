# Arduino-Ultrasonic-Sensor
A simple Arduino project that uses an HC-SR04 ultrasonic sensor to detect nearby objects and indicate their presence using LEDs.

Features:
- Detects objects using an HC-SR04 ultrasonic sensor.
- Red LED turns on when an object is detected within the set distance.
- Green LED stays on when no object is detected.
- Easy to understand and modify for beginners.
